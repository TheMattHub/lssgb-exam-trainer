# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies to issues, pull requests and every other project space.

In short: be respectful, assume good intent, and keep feedback on the content, not the person.

To report unacceptable behaviour, open an issue or contact the maintainer via GitHub.
