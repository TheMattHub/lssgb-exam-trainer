# Security

LSSGB Exam Trainer is a static site: HTML, CSS, JavaScript and data files, with no backend, no accounts and no network requests. Progress stays in the visitor's browser. A Content Security Policy allows only the site's own scripts, styles and images.

## Report a vulnerability

For anything sensitive, such as a way to run script through a data file or an imported progress file, use GitHub private vulnerability reporting: the repository's **Security** tab → **Report a vulnerability**.

For non-sensitive matters, open an ordinary issue.

Only the latest version on the `main` branch, as served on GitHub Pages, receives fixes.
